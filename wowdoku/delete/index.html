Data request

Request deletion

Wowdoku has no account. The data we hold is linked only to a random installation identifier created by the app.

How to submit a request

  1. Email support@arioapps.com with the subject “Wowdoku data deletion”.
  2. Include your device model and the approximate date you installed the app.
  3. We delete matching analytics records within 30 days.

Stop collection

Uninstalling the app stops all collection. It also removes local progress and resets the installation identifier.

Google advertising data

Ad data held by Google is managed through Google’s controls at My Ad Center. Ario Apps cannot delete data held only by Google.

This page applies to Wowdoku, Android package and iOS bundle com.trine.wowdoku.
